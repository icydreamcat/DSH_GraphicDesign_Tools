# 一条被连错三次的规则：图层遮罩的溶解只能用单块整盒 alpha fade

> 来源：本项目（铃兰「春之颂」）重做过程中的实测。
> 三次失败、三次诊断、一次成功。**每次失败的原因都已定位到具体渲染产物**，不是推测。

---

## 结论（先给规则）

**要让人物/素材的下缘淡入纸面，只有一种写法是对的：**

```json
"mask": { "shapes": [
  { "shape": "rect", "x": X, "y": Y, "w": W, "h": H,
    "paint": { "type": "fade", "angle": 90, "from": 1, "to": 0,
               "gamma": 2.6, "color": "#FFFFFF" } }
] }
```

- **一块、覆盖形状自己的整个盒、纯 alpha**
- `angle: 90` 的 t 是**从上往下**；`from: 1, to: 0` = 上实下透
- **`gamma > 1` 使前段缓、末段陡** —— 溶解因此落在下段，上半身保持完整
- **`color` 必须写**（省略时默认是黑，会在边上叠出一条暗带）

---

## 三次错法，各自的现象与证据

### 错法① `blend: 'multiply'` 做溶解 —— 压暗，不是透明

```js
{ paint: { type: 'fade', angle: 90, from: 1, to: 0.5, color:'#FFFFFF' },
  blend: 'multiply' }
```

**现象**：素材下缘仍是一条硬边，只是颜色暗了一档。
**为什么**：multiply 是**调色**运算，不是 alpha 运算。它把像素乘暗，边缘照样存在。
**这条最容易骗人**，因为渲染报告里的 `maskRetained` 会下降（0.927 → 更低），看起来像"遮罩生效了"，但那是被压暗的像素，不是被去掉的像素。

> **判断法**：把渲染结果在边缘处 1:1 裁出来看。压暗与透明在缩略图上看不出差别，在 1:1 下差别是决定性的。

### 错法② 用多个部分矩形叠遮罩做渐变 —— 互相打架

```js
mask: { shapes: [
  { rect: 整盒, fade 顶 ... },
  { rect: 下半盒, fade 底 ... },     // ← 两块同时作用于同一区域
  { rect: 顶部 6%, fade ... },
] }
```

**现象**：人物**脸被洗掉**，中间挖出一片雾。
**为什么**：两块遮罩在同一区域叠加，合成语义不是"相加"；下半盒那块在它自己的盒内还影响到了上半部分。
**更强的证据**：报告里 `maskRetained` 从 0.927 掉到很低的数，而**画面上少掉的是脸**——数字看起来"遮罩更强了"，实际是错的。

> **判断法**：任何一次遮罩改动后，先看**人物的脸还在不在**。脸是唯一不能丢的东西。

### 错法③ 截断位置切在内容上

**与遮罩写法无关，是取景问题。**
`region-ink` 实测源图 `hero.png`：

```
y 0.88–1.00   每格占用 1.00，columns with <1% ink: none
```

**整块矩形都是"有墨"** —— 抠图抠掉的是白色，但原图背景里的**淡粉花枝是半透明的、离白很远**，被当成内容保留。所以这不是人物轮廓，是一块矩形内容；底边永远是一刀切，**切在哪里就在哪里切**。

**推论**：这类素材的底边**必须用 alpha 溶解解决，不能指望轮廓自然收口**。

## 附带查明的两条

### 一、变量字体的 weight 令牌在 font shorthand 里无效

`typography-and-scale` 已写明，本项目复核：**`SansSC` 是变量字体，`wght` 轴 100–900，默认 100**。
`'900 48px SansSC'` 与 `'400 48px SansSC'` 测出来一样，且不作处理时**默认落在 100（发丝级）**——而发丝级看起来像"有意的风格选择"，极易被当作设计决定交付出去。

**本项目处理**：不使用 weight 令牌，改用**静态字体**（HanSansMedium / HanSansBold / NovecentoMedium 等），把不确定性去掉。

### 二、我对自己引擎文档的一个错误信任

我先前的笔记写着「`SoukouMincho` 的汉字缺 `兰`/`颂`（豆腐）」。
`design_system what:"fonts"` 的实测标注是：**`SoukouMincho` — "fine CJK Mincho, **full CJK coverage**"，`scripts: ["hans","latn"]`。**

**是我的测量错了，不是字体缺字。** 我据此把它从汉字用途里排除了好几轮。
→ **规则：字体覆盖范围要以 `design_system what:"fonts"` 的 `scripts` 字段为准，不要凭一次渲染的字形就下结论。**

## 沉淀成检查项

放进交付前自检：

- [ ] 素材边缘处 **1:1 裁一张**，确认是透明而不是压暗
- [ ] 遮罩改动后，**确认人物的脸还在**
- [ ] 溶解用**单块整盒 `fade`**，不叠第二块，不加 `blend`
- [ ] `fade` 的 `color` **写明**（省略＝黑）
- [ ] 任何"数字变好了"的改动，**都要看画面**——`maskRetained` 下降不代表遮罩对了
- [ ] 字体覆盖以 `design_system what:"fonts"` 的 `scripts` 为准
