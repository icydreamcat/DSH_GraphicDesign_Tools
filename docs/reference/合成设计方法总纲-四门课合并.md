## 第一部分 · 判定顺序（动手前必须走完）

这份顺序是从四门课里提炼的，**每一步都有出处**。

```
① 清点   这张图上实际有哪些物件、各是什么类别、在什么位置
② 判语言 参考图是高频石版还是线性水彩？——决定手法能不能搬
③ 定动线 读者第一眼落在哪，视线沿什么路径走
④ 定光轴 光从哪来。★ 必须早，"搞错了后面全错"
⑤ 分明暗 高光区 / 灰部区 / 暗部区——先分区，后放物件
⑥ 分角色 标签（排版）／道具（材料）／装置（系统）／注释（信息设计）
⑦ 分饱和 高饱和放暗部；高亮放边缘
⑧ 交错   高反射与低反射交错；厚与薄交错
⑨ 造型   道具先在形状上做对（弯折／撕边），再谈效果
⑩ 效果   外阴影 + 内阴影成对；双向阴影；反向阴影
⑪ 质感   靠单个物件**内部**的细节数量，不靠增加物件数量
⑫ 删除   四角层次少；动作是"删东西"，不是"调淡"；"哪些部分不重要"
```

### 各步的出处

| 步 | 课程原话 |
|---|---|
| ① | 本项目建立：**清点先于测量**（见 `清点先于测量.md`） |
| ③ | Vol.13 大纲：「**视线轴是确定构图的第一要义**」 |
| ④ | Vol.13 大纲：「**光线是确定画面整体明暗轴线的关键**」；字幕「**因为一开始如果把阴影的方向搞错了**」 |
| ⑤ | 细节课：「构图是形成作品的第一步」，画面标注「高光区／灰部区／暗部区」 |
| ⑦ | 细节课：「**高饱和物体在暗部环境下**」；分析笔记：「高亮的点**只在画面的边缘位置**……**舒缓画面的重心**，分散到边缘区块」 |
| ⑧ | Vol.13 大纲：「让**高反射材质和低反射材质交错出现**／让**厚度存在差异**的内容交错出现」 |
| ⑨ | 纸张课：「所以我**推荐你变形工具**」「矩形画好后贴一层**布料的纹理**」 |
| ⑩ | Vol.13 大纲：「**关于双重阴影的必要性**——光源不是单一的／物体本身之间存在折影／阴影末端有微妙的厚度」 |
| ⑪ | Vol.13 大纲：「**质感来源于不完美和细节的数量**」 |
| ⑫ | ARK 课字幕：「**右上角和左下角的层次会少**」「**就意味着你一定要删东西**」「不可能像我的合成一样**搞成千层饼**」「**哪些部分是不重要的**」 |

## 第二部分 · 从零做一个元素（四条完整流水线）

### 2.1 印章 —— 半调网屏

```
简形 → 滤镜→滤镜库 → 图像→模式→位图→半调网屏（改频率）
     → 选择→色彩范围→高光（去白） → 建选区填色 → 印章
```
**要点**：半调网屏是把"矢量图形"变成"印刷质感"的**统一工序**。
过了这道工序的元素**属于同一套语言**——这是统一风格最省力的做法。

### 2.2 金属件

```
画一个矩形 → 斜面与浮雕 → 内阴影（自下而上的反光）
           → 第二层内阴影（带角度的光线偏移） → 投影（厚度）
```
**字幕**：「这个模型呢」→「你就是需要这种效果」→「然后加一个**颜色叠加**图层」
**金属的颜色依据光线颜色**，不是自选"金属灰"。

### 2.3 纸张

```
矩形 → 网格变形（弯成摊开的书页）→ 图层效果做"缝合的边"
     → 在纸**内部**放一个方向性渐变（受光）
```
**字幕**：「**他会把右半面的纸张给照亮**」→「这边是一个**渐变**」
**要点**：**平面矩形加多少效果都只是色板；先在形状上被弯过，才是纸。**

### 2.4 布带

```
① 矩形 + 布料纹理（纹理太亮要调）
② 方向性渐变 → 褶皱凸起（一个矩形＋一个渐变＝一道褶）
③ 侧面亮面 → 混合模式改「颜色减淡」
④ 侧面暗面 → 混合模式改「正片叠底」
⑤ 两侧收口处做光影变化
⑥ 文字 = 叠加 + 柔光（**不用置换**）
```
**要点**：亮面暗面**不是两种颜色，是同一个矩形换混合模式**。

### 2.5 光线

```
① 光线图 = 白（亮光）+ 光源色（讳色），白色尽可能多、朝向作品中心
② 底色纯黑，图层混合模式改「滤色」去掉黑
③ 用组嵌套蒙版解决渐变
④ 主光源用白色画笔，混合模式改「亮光」→ 朦胧光效
⑤ 有颜色的光源：可集中在光源一侧，也可沿光路衰减；蒙版范围应在主光源处
```

## 第三部分 · 风格怎么拿捏

### 3.1 结论：不要纠结风格

ARK 课字幕（§4/§5）：
> 「**就是大家太纠结风格问题**」「**不需要把这个问题看的多么的复杂**」
> 「**你就不要想着去概括它是什么风格**」「或者**完全无法描述它的感觉**」
> 「**首先就去找参考**」「**什么元素是这个风格最为常用的**」
> 「**对做细小的差异化**」

**做法**：不先定义风格 → 找参考 → 抽出该风格最常用的元素 →
在自己的稿上做**细小的差异化**。同时探索多个方向（「把能探索的风格其实都**探索了一遍**」）。

### 3.2 材质族交错（风格的技术抓手）

ARK 课那张素材分类表（画面原文）：

| 组 | 物件 |
|---|---|
| 底 | 信纸 · 木纹 BG |
| 皮革 | 皮革贴子 |
| 玻璃 | 笔记本 · 玻璃瓶子的特殊斜光线 |
| 立体 | 地图-立体书 |
| 纹理 | 贴纸 · 棕色纸胶带 · 斜纹纸 · 引理夹 · 夹子 |
| 层次 | 瓦楞纸 · 玻璃钢球 · 挂胶漆和透明塑料卡片包装 |
| 卡片 | 夹层纸 · 有多层材质的纸片 |
| 其他 | 半透明的植绒文件夹 · 心形、圆形植绒布 |

按材质分三类，**每类做法不同**：

| 类别 | 课程展示的物件 | 做法 |
|---|---|---|
| **纸张类合成** | 快递单 / 车票 / 停车罚单 / 发票 / 贴纸 / FRAGILE 运输贴纸 | 差异化材质（四种纸不一样） |
| **金属类合成** | RHINE LAB 输液袋 / 金属扣 / 拉环 | 矩形 + 斜面浮雕 + 双内阴影 |
| **塑料类合成** | 名牌 / 计时器 / 胶带 | 高反射 + 主次反射 |

### 3.3 「一个基础图形＋复制」—— 这是**反例**，不是方法

ARK 课字幕：「**你先画一个作为一个**」→「然后立刻在**基础图形里面复制一个**」

**⚠️ 建档后修订**：这一段曾被当成"统一风格的手法"来用，结果被用户判定为
「你又堆了一堆没有质感的基础图形上去，互相之间也没有主题和关联，最后用数据告诉我量达标了」。

原稿里那条分界更准（用户原话）：

> 「你应该**比对他们的复杂度和手法**，然后**单独思考你做的图需要什么**，而不是照搬」

**借复杂度与手法，不借内容与形式。** 同一形状按不同尺寸复制多次 **是失败模式**；
系统 = **一个基础单元 + 多变体**，沿眼能读的三轴变化（哪个形 / 多少个 / 多重）+ 位置上的密度。
判据见 `design-judgement`，工序链见 `craft-and-material`。

**他自评**：「**把元素拆分做成价目表**」
字幕：「**但是尽量做出一点差异**」「**对做细小的差异化**」

**整套物料（封面/菜单/票根/通行证/小贴士页/计分卡）都是这样来的。**
他的 PS 图层名几乎全是 `分组`/`矩形`/`圆角矩形`/`曲线`——**结构极简，靠复制和换色铺满**。

### 3.4 复古的四个特征（借语言，不复刻工艺限制）

1. **粗字重**——「受限于**传播途径和成本考量**……**加粗放大**……**过目不忘**」
2. **手绘**——「**当时的摄影技术以及成本问题**」，分**写实、线稿与卡通**
3. **几何图形**——「**几何图形分区排版**……**整体布局错落有致**」；放射线是「**非常普遍的要素**」
4. **回形字 / 半调**

字幕：「**你已经没有那么多印刷上面的限制了**」——**借它的语言，不复制它的工艺限制。**

## 第四部分 · 质感怎么做（细节课的核心）

### 4.1 一个物件的完整拆解（计时器，逐层）

```
数字本体 → 矢量智能对象 → 智能滤镜·添加杂色
         → 拷贝 → 智能滤镜·添加杂色        ← 重影
主反射 矩形 → 高斯模糊                       ← 大而虚
次反射 组 → 高斯模糊                         ← 小而实
组 1 的投影 拷贝 2  ← 右方阴影
组 1 的投影 拷贝    ← 下方阴影
"组 1"的投影 拷贝   ← 透过缝隙
图层 3 → 斜面与浮雕 / 内阴影 / 添加杂色 / 边框阴影（两侧）
模拟油污                                     ← 单独一层
```

**六条可执行的**：
1. **反射分主次**——不是一块高光，是两层反射（大而虚 + 小而实）
2. **投影分方向**——右方 / 下方 / **透过缝隙**，三个独立
3. **杂色加多处**——数字本体、重影、面板
4. **不完美专门做一层**（模拟油污）
5. **边框阴影分两侧**——跟随光线方向，不四周平均
6. **斜面与浮雕 + 内阴影** 是厚度，**加杂色** 是质感，分开做

### 4.2 压暗的三条规律

> 「如果**距离光源远，就会更暗**，并且**含有黑色部分的细节会更模糊**」
> 「物体的**饱和度同样在暗处会削减**」

**这条纠正了一个长期错误**：加"压暗"不能叠半透明黑——
那会压低明度而**保持饱和度**，真实情况是**饱和度也掉**。
正确做法是往**低饱和的暗色**走。

## 第五部分 · 我实测过的（可信）与没实测的（不可信）

### 已验证的做法（做法本身，不含产出物路径）

| 做法 | 参数 | 结果 |
|---|---|---|
| 光线滤色叠深底 | 图层 `blend: "screen"`，光线图底纯黑 | 光线成立 |
| 超采样画布 | 3× 绘制后降采样 | 曲线锯齿消失 |
| 金属明暗用**渐变**不用分段 | `createLinearGradient` / `createRadialGradient` | 色带消失 |
| Catmull-Rom 稠密采样 | 稀疏控制点 → 240 点采样 | 折线变曲线 |
| 徽章 = 轮廓族 + 内场 + 徽记 + 双描边 + 齿饰 | 一套构造，八个变体 | 可复用 |
| 布带 = 纹理 + 方向渐变 + 上下缘亮暗 + 收口 | 同上 | 可复用 |
| 金属扣 = 矩形 + 斜面 + 双内阴影 + 压印槽 | 同上 | 可复用 |

### 教训（都踩过）

- **按角度分段填纯色 → 硬边"色带"**；必须改**渐变**
- **平面矩形加效果 → 永远是色板**；必须先在**形状上弯过**
- **低分辨率上画曲线 → 锯齿/多边形**；必须**超采样**
- **工具挑错会静默无用**：`mass-profile` 测 alpha 占用率，对**全不透明**的插画返回全 1.00，信息为零
- **图层 `stroke` 效果会"挖空"填充**：文字加描边要**先铺一层实心再叠描边层**
- **`gamma < 1` 会让渐隐更慢**（方向容易搞反）；底带用**实心纸带**比调曲线可靠
