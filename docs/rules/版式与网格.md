# 规则 · 版式与网格

> **纯结论与规则**，按内容归类。不讲"怎么得来的、曾经错在哪"——那是案例文献的事。

**先定层，再定密度。面积占比相同不等于设计相同。**

---

## 一、两种表面，两套版式规则

| 表面 | 版式 |
|---|---|
| **炭面**（深色、界面） | **仪表型用径向**；元素分散、线细、层次多 |
| **纸面**（浅色、文档） | **阅读型用列网格**（并把格线画出来）；线更重 |

**不要互换。** 阅读型版面用径向、仪表型界面用列网格，都会立刻读错。

---

## 二、密度：先定层，再定密度

| 指标 | 目标 |
|---|---|
| 独立区域数 | **40 个以上**（精细可达 300） |
| 单个最大区域占画布 | **≤ 15%** |
| 1px 线占比 | 深色面 **38%–55%**；浅色面由 2px 反超 |

**"元素要多、要淡"是**不完整**的处方——它给了密度，没给结构。**
平面上撒一百个 6% 的记号是糊；**把它们分到 3–4 个深度层上才读成系统。**

**所以顺序是：先定层，再定密度。** 反过来做不出来。

---

## 三、细节：不封顶，不许同质，不许没理由

### 3.1 均匀 vs 局部——有/无的判断，不是一个倍数

- **均匀铺满的纹样读成"壁纸"**
- **局部出现的纹样读成"制图"**

**规则**：底纹要**局部出现、局部消失**，不能均匀铺满。

至于"哪里密、哪里疏"，由**那一处的职务**决定：承载面安静、制图底繁密、
边缘记号稀疏——**不同职务本来就有不同的密度，这是结论，不是要凑的比例。**

> ### ⚠️ 这一条被写成过一个错误的判据，记在这里防止重犯
>
> 本文件曾经写着「局部细节峰值 / 最低值相差 **5–8 倍**」。那是从**一次**实测里量到的数字，
> 被搬成了通则，而它不成立：
>
> - **它不可判。** 要人先定义"区域"、再决定哪些进算。同一张图换一套分区，比值就变——
>   **它不是关于画面的量，是关于你怎么切它的量**
> - **它与真判据无关。** 真结论是**均匀 vs 局部**，那是"有/无"。倍数只是那次恰好落在那里
> - **它会骗人。** 实测教训：一张图报出 30 倍，据此判为"局部化过头"，
>   而真实的毛病是**同质**——两个完全不同的问题，同一个数字
>
> **通则**：一次实测的数字，只有在它**可判**且**与成因相关**时才能当判据。
> 否则它只是一个观察，写进案例里，不要写进规则。

### 3.2 同质化的细节等于没有细节

**13 张同一个构造复制出来的卡片，不是一个系统，是一次复制。** 它的信息量等于 1 张。

这是**细节太少**的一种表现——读者读完第一张就没有新东西可读了。

**判据（四条同时成立才算细节）**：

1. **能说出生成规则**——说不出生成一组元素的规则，就没有设计过这一组
2. **组内沿眼能读的轴变化**（哪个形 / 多少个 / 多重），不是一个形复制 N 遍
3. **每一处都承担一个职务**：是分区、是字段、是刻度、是标注，还是纯粹的填充？
4. **不是填充**——如果一处细节删掉后画面信息量不变，它就是装饰

**反例（真实发生过）**：一个基础图形＋复制铺满整套物料。
**正例**：一个基础单元＋多个变体，沿三轴变化，位置密度由区域职务决定。

### 3.3 密度应当来自哪一类元件

制图语言的高频低对比，靠的是**细线、刻度、字段分隔、基准标记、编号**这一层，
**不是靠再放一块内容**。

换句话说：**当画面显得空时，先问缺的是"更多卡片"还是"更高频的细节"。**
后者几乎总是答案——而且它同时抬高细节上限，不增加任何语义负担。

## 四、部件之间的关系是「职务」，不是「尺寸」

**这是把设计做成表格与做成画面的分界线，而它是一条结构规则，不是审美偏好。**

一张图里每个部件都在回答一个**不同的问题**。部件之间不是"大小不同、位置不同"，
而是**作用不同**。五种职务：

| 职务 | 它回答的问题 | 在画面上的样子 |
|---|---|---|
| **环境** | 这是什么东西所在的地方？ | 有质感的底：噪点、纤维、暗面。**不是一块平涂** |
| **装置** | 这东西被呈现在什么里面？ | 框、屏幕、板子、封套、纸边。**它给出边界与厚度** |
| **内容** | 要读的是什么？ | 纸、单据、卡。**被装置装着，不铺满全画布** |
| **动作** | 这里正在发生什么事？ | 一支斜压的笔、一段贴上去的胶带、一枚盖下的章。**角度与别的东西不一致** |
| **强调** | 哪里是要先看的？ | **极小面积的信号色**，落在记号上而不是落在装饰上 |

### 4.1 什么叫「有逻辑」

**逻辑不是把东西分类放进盒子，而是部件之间的三种真实关系。** 这三种没有一种能靠"等距排列的矩形"表达：

1. **压着**——一个部件盖住另一个（卡压住单据、回形针挂在照片上、胶带压过一行字）
2. **斜置**——部件之间**角度不一致**（胶带、卡、第二张照片、标签条全部是斜的）
3. **被画布边缘裁切**——内容主动"装不下"

**第 3 条最容易被当成失误，而它是手法。** 实测：一块封条被左缘与上缘**同时**裁切、
竖排标签与一条布带被右缘裁切、一块色片只剩残角。

**用意**：**用"装不下"暗示这是一堆摊开在桌面上的实物，而不是一页被排好的稿子。**
被裁切的东西一定比画布大——**它一句话就说明了"画面之外还有东西"。**

> ⚠️ **一张图里可能有三层"框"，必须先分清，否则会把 UI 边框当成作品的一部分。**
>
> 实测：**① 播放器/录屏的圆角框**（纯 UI，不属于作品）→ **② 画布边界**（作品的物理边界）
> → **③ 画面内部的框**（那张纸的边、照片的白边、卡片的边）。
>
> **部件被第三层裁切是正常的、也是要的；而没有任何部件穿过第二层。**
> 这一条是改正一个真实的误读：曾把"人物压在框上"读成了"人物探出边框外"，
> 而两者是不同的动作，画面上发生的是前者。

### 4.2 什么叫「好看」

在同一批实测素材里，好看来自四件事，**没有一件是"信息排得整齐"**：

1. **一个明确的主体**，占画面约六成（实测 55–70%），而不是十几个等大的块
2. **一个框**把主体装起来，于是主体与背景之间有了**层次**而不是**并置**
3. **光线统一**：**一个光源、一个方向、一条单调递减的明度梯度**（见 4.3）
4. **不等**：斜置、错位、被裁切。**绝对的对齐与等距属于表格，不属于画面**

### 4.3 光线是骨架，不是效果 —— 这一条能判出表格

实测：成品图顶部偏左有一条**贴住画布上缘的过曝白斑**，是全图**唯一的高光锚点**；
围绕它一圈白雾光晕，**全图明度自上而下单调递减**，右下最暗。
而且**每一件物件的曝光度各不相同**（实测 `-0.61` 与 `-0.67` 两组），
投影统一 `角度 130° / 距离 1px / 大小 4px`。

字幕原话：
> 「如果**距离光源远，就会更暗**，并且**含有黑色部分的细节会更模糊**」
> 「物体的**饱和度同样在暗处会削减**」

**所以"逻辑"在这里有确切含义**：不是把东西分类，而是**所有部件被同一个光源排序**——
谁离光源近谁亮，谁远谁暗，暗处降饱和，投影朝同一个方向。

**由此得到一条极锋利的自查（也是判据）**：

> **表格不会有投影，也不会有光照梯度。**
>
> 如果一张图把颜色全部拿掉之后，明度是平的——没有高光锚点、没有衰减方向、
> 每块区域的亮度一样——**那它就没有骨架，无论它携带了多少信息。**

**而这一条是可以照着做的**：先定一个光源位置 → 定一条衰减方向 →
给每件物件按它离光源的距离取不同的曝光 → 投影全部朝同一方向。
**这四步做完，一张图就有逻辑了；一步没做，信息再多也是扁的。**

### 4.4 检查骨架的方法：黑白观察层 + 沿动线走

**这是"有没有骨架"的可操作检查，不靠眼睛估。** 实测工序：

1. 在**最顶层**加一个 **`黑白` 调整层**，整图变灰
2. **沿着观者会看的那条动线**走一遍
3. **找明暗交替**——亮、暗、亮、暗。对不上的地方，就是缺部件的地方

字幕逐字：
> 「**让我们沿着我们的动线一条线去看**」
> 「**就是让明暗交替出现**」

**为什么这条重要**：它把"好看"变成了一个可以逐点检查的量——**动线上有没有节奏**。
一个只有明或只有暗的画面，无论有多少内容，沿动线走一遍就是平的，**那就是表格。**

**而补的方法是"一张一张铺"**：实测作者在顶层新建了 **18 个图层**（`图层 715…732`）
逐个补光，配合 `曝光度` / `色相·饱和度` / `亮度·对比度` / `曲线` / `色阶` / `黑白` / `纯色` / `渐变`
这类调整层。**不是重排元素，是逐处补光。**

### 4.5 光是一个独立构造，不是图层的属性

实测两次独立确认，来自两份不同素材：

| 素材 | 证据 |
|---|---|
| 一份成品的图层树 | 一个叫 **`光线`** 的组，组内**十一层以上**，且同时含**「提亮背景」与「压暗环境」**两类相反的层 |
| 另一份成品的图层树 | 相邻两层 **`图层 …斜面阴影`** 与 **`图层 …斜面高光`**——一对相反层；作者另在外部工具里**手画一条直线当光轴** |

字幕：「**就是从右上往左下照射的话**」「**你是不能随便的去定它的光**」

**所以做法是**：把光收成**一个独立的组**，压在**全部内容之上**，组内至少要有
**主光源 / 衰减 / 提亮 / 压暗**四种层。**它不是一个"效果"，是一层构造。**

**最后那句是纪律**：光一旦定了，**任何一处都不能单独改**——
改一处就要回头改全图，因为全图的所有部件都是被同一个光源排序的。

### 4.6 素材复用必须"去撞车"

**同一个素材在画面里出现两次，观者会看出来**，那时两次出现会互相消解——
读者会认为"这是同一个东西被放了两次"，画面的可信度就断了。

**两种解法，实测各一**：

| 解法 | 做法 |
|---|---|
| **颜色差异** | 同一形状，两次出现取不同色（色相/饱和度、颜色叠加） |
| **遮挡差异** | 同一形状，两次出现被不同的东西压住/裁切，于是轮廓不同 |

字幕（连续四帧讲同一件事）：
> 「**很怕素材复用这个点**」「**要么就是颜色产生差异**」「**被遮挡关系也是**」「**的办法去暗示观众**」

**判据**：一处素材被复用时，**列出它的两次出现，说明各自靠什么被区分开**。
若答案是"没有区别"，那它不是复用，是重复——而**重复的部分读者会跳过**。

### 4.3 反例就是"表格化"——一个自查

> **如果你把每个部件的位置逐个写下来，能组成一张整齐的表（等宽、等高、等距、对齐），
> 那它就是一张表。**

这条自查能判出真实发生过的一种失败：四条等高的横带、每带三到四张等宽卡片、
每张卡一个标题一段正文。**它有信息，但没有任何一个部件在回答一个不同的问题**——
十三张卡回答的是同一个问题十三遍。

**而当每个部件回答的是同一个问题时，读者读完第一张就没有新东西可读了。**

## 五、两条"品牌级"的版式纪律

**这两条来自对 42 张同体系成品封面的实测统计**，覆盖率分别是 41/42 与 42/42——
**它们是这套语言最强的单一共同点**，比任何单张作品的做法都更值得抄。

> **⚠️ 一句话说清它们的性质**：这不是"某位设计师的做法"，而是**一套语言的纪律**。
> 它们能在这个覆盖率上成立，正因为被反复执行。**要借的是这条纪律，不是这些具体的字。**

### 5.1 版式锁定：标志永远在同一个位置，且永远小于主标题

**41/42 张**：一个手写体汉字标志 + 其下一个**细白矩形**内的拉丁小字。
- **位置永远靠中左**（不是居中、不是右上）
- **尺寸永远小于主标题**——它是"署名"，不是"标题"

**为什么值得抄**：一旦标志有固定位置与固定层级，**它就退到背景里去了**，
主标题因此获得全部注意力。**标志每次换个地方，读者每次都要重新找它。**

### 5.2 双语文案锁：拉丁在上、中文在下

**42/42 张**：主标题由两层组成——
- **上**：大写拉丁，**细体、宽字距**
- **下**：中文，**粗体**

**44 张里一张没破例，说明这不是偏好，是硬纪律。**

**为什么**：拉丁细体宽字距在上提供**"技术/制式"的语气与呼吸**，
中文粗体在下提供**"这就是内容"的重量**。两者职务不同，**所以不能互换，也不能合并成一层**。

## 六、面积占比相同 ≠ 设计相同

一个区域占画布 42%，你也放一个占 42% 的色块。**占比对上了，但那 42% 不是一块色，
是一整片有内部层级的编排。你用填充替代了编排。**

**"填满"不是"留白"，"占比正确"不是"设计正确"。**

### 度量方法

取该区域的矩形，统计两件事：

```
主导平涂色占比 = 出现次数最多的那个 RGB 占该矩形的比例
可分辨色数     = 该矩形内出现的不同 RGB 个数
```

### 判据（取自参考的 UI 表面实测）

| 指标 | 合格线 |
|---|---|
| 大区域主导平涂色占比 | **< 25%**（实测 3.0%–20.8%） |
| 大区域可分辨色数 | **200–7000**（视职务：安静的承载面 188–200，最丰富的制图底 1383–7032） |

**"被设计过的面板"的五条**（缺哪条就是缺哪条，不是程度问题）：

1. 内部有层级（同级不止一个尺度）
2. 边界不是一条齐整的矩形（有切角、有断开、有线脚）
3. 有局部细节（不是均匀纹理）
4. 有一个明确的焦点装置
5. 与相邻区域的关系是可读的（对齐、让位、穿插）

**判据**：把这块区域的文字**全部删掉**，它是否仍读起来像"一块被设计过的面板"而不是"一个色块"？

## 七、细节 ≠ 层级

- **细节多不等于层级清楚。** 两者可以独立缺失
- **细节在一个物件内部，不在物件数量上。** 加物件不等于加细节

---

## 八、长图版式

```
色带分区 → 字段名黑牌 → 三角条目 → 发丝线分隔 → 关键词 → 等宽数值
```

长图的读法是从上到下单向推进的；**分区靠色带，字段靠黑牌，条目靠三角，层级靠发丝线。**

---

## 九、网格的检测与读法

- **测出的列距只代表"画了线的网格"**，不代表"分块的网格"：
  一个视觉上明显的瓷砖格也可能测出 `null`
- **`null` 只能读作"未检出"，绝不能当作"不存在"的证据**
- **径向组织**（围绕一个圆心的分度与弧）与**列网格**是两种不同的组织方式，
  要用对场合，**不要互相替代**

---

## 十、每页必须演示它自己的论点

- 每页能一句话说清"它要证明什么"，且**页面本身演示了它**
- 十页**不是**同一个模板盖出来的：边距、尺度、焦点装置各不同
- 声称了对比 → 图里**两个项都在**

---

## 禁止清单

- ❌ 阅读型版面用径向 / 仪表型用列网格
- ❌ 在平面上直接堆密度（没先分层）
- ❌ 底纹均匀铺满
- ❌ 用填充替代编排
- ❌ 靠加物件来加细节
- ❌ 把 `null` 读成"不存在"
- ❌ 一个模板盖十页
