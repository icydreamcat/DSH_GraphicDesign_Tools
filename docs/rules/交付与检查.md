# 规则 · 交付与检查

> **纯结论与规则**，按内容归类。不讲"怎么得来的、曾经错在哪"——那是案例文献的事。

交付不是"我觉得可以了"，是**逐条能给出证**据**。

---

## 一、交付前逐条过（每条都要指出落在画面的哪一处）

- [ ] **渲染报告的 `warnings` 数组为空。** 不为空就**点名每一个失败图层与原因**
- [ ] **没有元素压在人脸或胸口上**——**看 1:1 裁切，不看你的意图**
- [ ] **没有片状元素是半透明的**（除非半透是那个物件的真实属性）
- [ ] **声明的层序 = 实际层序**
- [ ] **没有上一轮的残留**：替换素材必须在**同一次改动里**删掉旧的
- [ ] **每个组都能说出生成规则**
- [ ] **颜色是单独受控的**，不是顺带的
- [ ] **元素数、材质族数、字号级数不低于参考图**
- [ ] **图被看过了**，不只是看了数字

---

## 二、图层顺序是设计变量，不是管道

**在声明深度层的同时一并声明顺序。**

两类静默失败，都会发生：

- **纸画在人物之前** → 读作"纸是透明的"。人物被画在纸上面，眼睛把这次重叠解释成纸透过来。
- **纸张纹理层比它所属的形状大一圈** → 在形状外留下一圈浅色矩形，读作"浮在纸上的方块"。

**规则**：
- 一个半透明的点缀（和纸胶带、一层染色）是合法的，**当且仅当半透明是那个物件的真实属性**
- **一整张纸画成半透明不是。** 真纸不透明——**降低它的明度，不是它的不透明度**
- **每次都要核对**：场景里声明的顺序，与图层列表里的实际顺序是否一致

---

## 三、先读 `warnings`，再信那张图

**每一个失败的图层都在那里，带着原因；而图里永远看不到它**——图层就是不在，渲染看起来仍然合理。

- 一个不在枚举里的混合模式名 → 六层纹理静默消失，画面变平，**看不出原因**
- 一个拼错的路径串 → 四条连线从未绘制，构图失去唯一的结构
- 一个写成一整块不透明矩形的蒙版 → 200 个"斑点"各自覆盖整个画布，把底冲成灰

**未读的 `warnings` 等于不知道图里有什么。**

---

## 四、先 1:1 裁切，再谈缺陷

- 缩略图**恰好隐藏**那些最要紧的失败；多数真实缺陷在真实分辨率的裁切里才显现
- **工具与眼睛冲突时，信图，然后去找那个数字看不到什么**

**已知的数字盲区**（工具量得到的东西有边界）：

| 数字会说 | 实际 |
|---|---|
| "字与底只有 1.04:1，读不出" | 字坐在**自己的面板**上，很清楚。验证器只比"字色 vs 声明的底"，**看不到中间那层** |
| "80 层文字全部 ≥ 4.5:1" | 一个外发光把暗色**盖在笔画上**，字是灰的。工具比的是"声明墨色 vs 底子"，两者都没变，**改的是字形** |
| "`flatShare = 0`，没有这个颜色" | 该色以**自发光**存在，边缘柔和，不构成平涂 |

---

## 五、不要让"文字被盖住"和"对比度不够"混为一谈

**这是两个完全不同的毛病，量对比度量不出后者。**

- 对比度量的是**墨色 vs 底子**。而某些效果（外发光配正常混合、描边）改的是**字形本身**——
  墨色没变、底子没变，量出来的比值全绿，**而字是灰的**
- **这一条只有 1:1 裁切能看出来**

---

## 六、标为"已知缺口"的东西要写下来

- **不可达的能力**（某个效果做不出来、某类素材缺失）→ 写进缺口清单，**不是假装它不存在**
- **未验证的推断** → 标【推断】，并说清它没被验证
- **降级的结论**（只看过缩略图就下的判断）→ 明确降级为"印象"，**不作为规格**

---

## 七、遮罩溶解：只有一种正确写法

```json
"mask": { "shapes": [
  { "shape": "rect", "x": X, "y": Y, "w": W, "h": H,
    "paint": { "type": "fade", "angle": 90, "from": 1, "to": 0,
               "gamma": 2.6, "color": "#FFFFFF" } }
] }
```

**一块、覆盖形状整盒、纯 alpha、`gamma` 控制溶解位置、`color` 必须写。**

三种错法，各自留下可见缺陷：

1. **用 `blend: 'multiply'` 做溶解** → 那是**压暗不是透明**，边还在。
   更坏的是 `maskRetained` 会下降，**看起来像生效了**
2. **多个部分矩形各叠一点遮罩** → 互相打架，把中间洗掉（在案例里洗掉了一张脸）
3. **把截断位置切在内容上** → 如果源是整块有墨（实测：没有一列墨占比低于 1%），
   底边只能靠 alpha 溶解，找不到天然边界

---

## 八、两道闸门

**GATE 1 —— 第一个元素之前。** 四问与判定顺序写完，否则停。
放在第一个元素之前的每一样东西，都是在盲着放。

**GATE 2 —— 交付之前。** 第一节那张清单，**每一条要给出证明值，不许写"是"**。

**两条都不靠声明来通过。** 能机判的由工具判，判不了的留给作品的所有者。

---

## 九、禁止清单

- ❌ 用"我觉得可以了"代替逐条检查
- ❌ 不看 `warnings` 就信那张图
- ❌ 用透明度做层次
- ❌ 替换素材时不删旧的（两代同时留在版面上）
- ❌ 只在缩略图上判断缺陷
- ❌ 把 1:1 裁切能看出的问题交给数字去判，或反过来
- ❌ 把未验证的推断写成结论
