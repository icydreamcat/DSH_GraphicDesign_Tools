# 规则 · 制作与材质

> **纯结论与规则**，按内容归类。不讲"怎么得来的、曾经错在哪"——那是案例文献的事。

**一门手艺，一个统一目标——不是一份材质配方库。**

---

## 一、核心不是操作，是"这些都能自己做出来"

课程真正教的不是"皮革怎么做、金属怎么做"，而是**这些东西原来都可以自己做出来**。

**要学的是基础原理与统一的实践方法，不是把材质一种一种记下来抄。**

推论两条：

- **一份抄下来却用不上的配方不是知识。** 本文件的操作段落是**链条**，不是让你照选的菜单
- **不要把方法的限制当成媒介的限制。** 遇到"我做不到某质感"时，先问这是媒介的限制还是方法的限制——
  「手绘质感」不是能力缺失，是**把其他素材加工成那种质感的工序**

---

## 二、判定顺序（动手前走完）

```
① 清点   这张图上实际有哪些物件、各是什么类别、在什么位置
② 判语言 参考是高频石版还是线性水彩——决定手法能不能搬
③ 定动线 读者第一眼落在哪，视线沿什么路径走
④ 定光轴 光从哪来            ★ 必须早，搞错了后面全错
⑤ 分明暗 高光区 / 灰部区 / 暗部区——先分区，后放物件
⑥ 分角色 标签（排版）/ 道具（材料）/ 装置（系统）/ 注释（信息设计）
⑦ 分饱和 高饱和放暗部；高亮放边缘
⑧ 交错   高反射与低反射交错；厚与薄交错
⑨ 造型   道具先在形状上做对（弯折、撕边），再谈效果
⑩ 效果   外阴影与内阴影成对；双向阴影；反向阴影
⑪ 质感   靠单个物件**内部**的细节数量，不靠增加物件数量
⑫ 删除   四角层次少；动作是"删东西"，不是"调淡"
```

## 三、复杂度从哪来

**不是渐变，不是不透明度。** 是物理事实：

| 来源 | 在页面上意味着 |
|---|---|
| **纸张的纤维与卷边** | 纸有纹理方向，表面受光不匀 |
| **投影随高度变化** | 平贴的投影紧而深；翘起的散而淡。**高度靠投影读出来** |
| **元素之间的物理牵连** | 绳、图钉、粘贴、盖章、骑缝。**这是让一堆散件读成一张图的东西** |
| **跨材质的一道共同工序** | 一个网屏、一个双色调、一种墨、一个光 |

**最贵的一条**：**它们不是纹理，是在模拟现实世界的东西；应该像现实一样可以叠，而不是用透明做层次。**

**用不透明度做层次，等于把纸变成描图纸。现实里纸是**不透明**的，所以叠就是**遮挡**。**
一张纸需要后退时，**降它的明度，不是它的不透明度**。

### 3.1 一个材质只需要两三个信号

**这是本节最省力、也最容易做反的一条。** 实测（对成品的逐层显隐判读）：

| 材质 | 成立所需的全部信号 |
|---|---|
| **纸** | **撕边**（一条边参差，就够） |
| **皮革** | **卵石颗粒 + 一圈白色虚线缝线** |
| **塑封 / 覆膜** | **斜向反光带 + 褶皱** |
| **网点印刷** | 同一形状内**一段噪点颗粒 + 一段网点**并存 |

**它不需要更多细节量。** 一个材质读到"是纸"或"是皮革"就停——再往上加的细节不再增加材质可信度，
只会增加噪点。

**由此纠正一个真实犯过的错**：把"细节不封顶"读成"给每个元素加更多细节"，
结果 251 个元素、41 个图层全是小方块，画面读起来像一张表而不是一件东西。
**缺的从来不是细节数量，是信号选得对不对。**

### 3.2 反光是一层盖在所有东西上面的东西

实测证据：斜向亮带**跨过文字与照片一起反光**。

**所以它是独立的一层覆膜，不是文字自带的效果。**
这一点决定了做法：想做出"塑封感"，不是给文字加描边或高光，
而是**在上面铺一层带斜向反光带与褶皱的层**，让它同时扫过底下的文字、照片和纸。

**它也是"物件之间发生关系"的最便宜证据**——一层反光同时盖住三样东西，
这三样东西立刻共处同一个物理世界。

### 3.3 关系比物件更出效果

拼贴感的三个来源，按实测强度排序：

1. **遮挡**——胶带压住一行字的上沿；一块板切掉另一块上的半截字
2. **残边**——白单据的边切过底层文字的笔画
3. **角度错位**——斜贴的小照片与水平的手写字**角度不一致**；胶带边缘参差、长短角度都不齐

**居中、对齐、等距是版式的逻辑；轻微的不齐、遮挡与角度差才是物件的逻辑。**
一条横跨字面的胶带比十个抽象记号更能说明"这是拼贴"。

### 3.4 份量：主体物件要占画布的大半

实测：白色单据占画布约 **60–70%**，是**主体**；胶带、小照片、条码、印章是**压在它上面的附属件**；
皮革卡退为**衬底**。

**所以一张图是"一个大物件 + 几个附属件 + 一层衬底"，不是"几十个等重的小元素"。**

**如果一个图形需要凑近才看清，它就不是图形，是标注。** 标注不承担内容，
而内容无处可去时就会落到大面积平涂和成串文字上——**那正是设计变成一张表的方式。**

### 3.5 立体感可以晚到，但表面材质不能缺

实测一个反证：某一段成品里**没有任何可归因于物件的投影或斜面**，
全部靠**表面材质 + 层叠关系**成立。

**结论**：**投影与斜面是后期才进画面的东西，而撕边、颗粒、缝线、反光带是打底就要有的。**
不要一上手就去调投影——先把材质的信号补上，投影是让物件离开纸面的最后一步，不是第一步。

### 3.6 「细节爆表」的真答案：先把物件做得够多够真

**这是本节最重要的一条，而且它与直觉相反：那个标题叫「怎样制作细节爆表的合成」的演示，
其"细节"主要不来自特效叠加，来自——把物件本身设计得足够多、足够真。**

作者自己的原话：**「以下就是我制作的一些基础的物品」**、**「对每个纸张做出了差异化的材质」**。

**实测的素材量**：一次性做出 **13 类基础物件**——

| 类 | 物件 |
|---|---|
| **纸张** | 快递单 · 车票 · 停车罚单 · 发票 · 驾照 |
| **贴纸** | `STANDARD SUBSTITUTION` 贴纸 · `FRAGILE` 运输贴纸（两套，一套低饱和、一套高饱和红） |
| **金属** | 金属 D 形环拉手 · 镜面铝箔袋 · 徽章 |
| **塑料** | 胶带 · 计时器 · 工牌 · 塑封袋 |

**每一件都有自己真实的字段**：车票上有票号 `53260`、`AGENT'S STUB`、手写签名；
罚单上有 `TICKET NO. 09875`、五个 `☐ $50.00` 勾选框、以及底部一整段法条文案；
快递单上有发货人、地址、邮编、二维码、条码、「周末与假日不派送」。
**所以物件不是"贴了个形状"，是"做了一份真的单据"。**

**推论——这条直接决定该做什么图**：

1. **先量产素材，再谈合成。** 这一步在设计流程里排在构图分析之后、动手合成之前。
2. **一物件的细节量是 3–7 个效果，不是 1 个。** 实测：单个金属挂钩 = 15 图层 / 4 组 /
   7 个图层样式（2 投影 + 2 内阴影 + 内阴影·渐变叠加·投影）+ 4 个调整层；
   单个计时器屏幕 = 添加杂色 ×2（数字本体 + 重影）+ 高斯模糊 ×2（主反射 + 次反射）
   + 一层（斜面浮雕 + 内阴影 + 添加杂色）。
3. **但要加在物件内部，不是并排更多物件。** 内部优先；数量是另一件事，靠整图的疏密分区来管。

### 3.7 三条可复制的具体旋钮

| 要做的事 | 怎么调 |
|---|---|
| **金属倒角强弱** | **内阴影的「阻塞」值**：0% → 倒角消失；24% → 有；**38% → 明显**。（实测旋钮，不是猜的） |
| **金属材质** | 套 `渐变映射`，**混合模式「强光」100%**。作者原话「直接 copy 这个渐变映射即可」 |
| **颗粒** | 用**智能滤镜「添加杂色」**，不是图层样式里的杂色——实测图层样式里的杂色参数**全程是 0%** |
| **阴影要有厚度感** | **不要只用一个投影**：复制投影层并**错开**，分成**下方阴影 / 右方阴影 / 透过缝隙**（后者配蒙版） |

### 3.8 「不完美」要有，但它是一层图层样式，不是一张贴图

**做法（实测，有名有姓）**：起**一个图层**，在它的**图层样式与智能滤镜**里同时表达三件事——

| 标注 | 用什么做 |
|---|---|
| `边框阴影` | `斜面和浮雕` |
| **`模拟油污`** | **`内阴影`** |
| `存在的指纹和划痕` | `添加杂色` 智能滤镜 |

字幕原话：**「此外为了增加真实感」「增加了两侧的阴影效果」「存在的指纹和划痕」**。

**所以"不完美"要专门起一层，但这一层上没有贴图——它是效果。**
两处记录曾经看起来冲突（一处写「模拟油污 单独一层」，一处写「全片没有独立的油污层」），
核对后是**同一件事的两种说法**：**"单独一层"说的是它有自己的图层，"不独立"说的是它不是一张素材图。**
两者都对，合起来才是完整规则。

### 3.9 物件之间靠三种东西连成整体

实测三重连接，三种都要有：

1. **红线/白细线**把不同物件互相连起来（成品图里成串）
2. **胶带条横跨多个物件**——它的功能不是装饰，是**暗示光源距离**（原话「来实现对于光源距离的暗示」）
3. **一根细绳贯穿画面**，而且**松紧本身是设计变量**：素材里专门对比了「**紧绷的细绳**」与「**松弛与紧绷**」两种状态

字幕：**「同时也将画面语言延伸至画面外」**——
**线延伸到画布之外，画面就不再是一个框，而是一个被截取下来的现场。**

### 3.10 成品大概率是"版式"，不是"一件被欣赏的物件" —— 一处必须说清的边界

对某份成品的判读结论是：**它是一张版式，不是一件可以被单独欣赏的物件。** 依据：

- **标题字压在上面**（教程标题与 `PART.02` 编号）——一件作品不会自带章节号
- **元素是"几十个"量级、平铺满整幅**，不是围绕单一物体构图
- **画幅是 16:9 横幅**
- **有明确的压/被压层级**：胶带与警示斜纹压在证件之上、框边压在最下、丝线又压在胶带之上
  ——那是**版面层级**，不是物理堆叠

**但它内部确实有零件级完整的物件**：计时器与金属挂钩都做到了镜面反射、油污、指纹、
主次反射、双向阴影。所以准确的描述是：

> **它是一件"高度完成的物件"加上几十个背景元素组成的版式封面。**

**这条边界要记住**：你要做的**素材**是零件级的完整物件；
而**承载它们的版面**可以是版式。两者不冲突，但**不能拿版式的密度去替代物件的完成度。**

## 四、元素之间要有逻辑，不是摆得近

**反例（都是真实做过的）**：胶带不粘任何东西、票根没有行程、印章不盖在文件上、计时器不计任何事。
每一件单独看都合理，**它们只是以正确的密度分布着**。

**正例**：把版面组织成**一份行装清单**——信、采买收据（带明细与合计）、邮戳骑跨折缝、
标签贴在对应对的物件上、**每一行一根线牵到它的物件**。

**同样的元素，同样的密度。** 区别在于每一样东西都有理由待在它所在的位置。

**规则**：加材质之前先回答**什么连着什么是**。如果答案是"它们分布得很均匀"，这一页还没有被设计。

## 五、四条工序链

### 印章 —— 半调网屏

```
简形 → 滤镜库 → 位图模式 → 半调网屏（改频率）
     → 色彩范围取高光（去白） → 建选区填色 → 印章
```
**半调网屏是把"矢量图形"变成"印刷质感"的统一工序。**
过了这道工序的元素**属于同一套语言**——这是统一风格最省力的做法。

### 金属件

```
矩形 → 斜面与浮雕 → 内阴影（自下而上的反光）
     → 第二层内阴影（带角度的光线偏移） → 投影（厚度）
     → 颜色叠加
```
**金属的颜色依据光线颜色**，不是自选一个"金属灰"。

**先用渐变，不要分段。** 沿路径逐点铺圆、每段填纯色会产生**硬边色带**；改成渐变后色带消失。

### 纸张

```
矩形 → 网格变形（弯成摊开的页）→ 图层效果做"缝合的边"
     → 在纸**内部**放一个方向性渐变（受光）
```
**平面矩形加多少效果都只是色板；先在形状上被弯过，才是纸。**

### 布带

```
① 矩形 + 布料纹理（纹理太亮要压）
② 方向性渐变 → 褶皱凸起（一个矩形＋一个渐变＝一道褶）
③ 侧面亮面 → 混合模式改"颜色减淡"
④ 侧面暗面 → 混合模式改"正片叠底"
⑤ 两侧收口处做光影变化
⑥ 文字 = 叠加 + 柔光（**不用置换**）
```
**亮面暗面不是两种颜色，是同一个矩形换混合模式。**

## 六、一个物件的完整拆解（示范：一个计时器）

```
数字本体 → 矢量智能对象 → 智能滤镜·添加杂色
         → 拷贝 → 再添加杂色          ← 重影
主反射 矩形 → 高斯模糊                 ← 大而虚
次反射 组 → 高斯模糊                   ← 小而实
投影 ×3：右方 / 下方 / 透过缝隙
斜面与浮雕 / 内阴影 / 添加杂色 / 边框阴影（两侧）
模拟油污                               ← 单独一层
```

**六条可执行的**：

1. **反射分主次**——不是一块高光，是两层（大而虚 + 小而实）
2. **投影分方向**——右方 / 下方 / 透过缝隙，三个独立
3. **杂色加多处**——本体、重影、面板
4. **不完美专门做一层**
5. **边框阴影分两侧**——跟随光线方向，不四周平均
6. **斜面与浮雕 + 内阴影**是厚度，**加杂色**是质感，分开做

## 七、压暗的正确做法

> 距离光源越远越暗，**并且含黑色部分的细节会更模糊**；物体的**饱和度在暗处同样会削减**。

**加"压暗"不能叠半透明黑**——那会压低明度而**保持饱和度**，与真实相反。
**正确做法是往低饱和的暗色走。**

---

## 八、光线

```
① 光线图 = 白（亮光）+ 光源色，白色尽可能多、朝向作品中心
② 底色纯黑，图层混合模式改"滤色"去掉黑
③ 用组嵌套蒙版解决渐变
④ 主光源用白色画笔，混合模式改"亮光" → 朦胧光效
⑤ 有颜色的光源可集中在光源一侧，或沿光路衰减；蒙版范围应在主光源处
```

---

## 九、密度与删除是同时的

- **"元素要多、要淡"不是"少"。** 多而淡，不是少而重
- **删东西不是调淡。** 要问的是"哪些部分不重要"，而不是把不重要的压暗
- **不可能做成一整张千层饼。** 四角的层次本来就少
- **质感靠单个物件内部的细节数量**，不靠增加物件数量

---

## 十、风格怎么拿捏

- **不要纠结"是什么风格"，不要试图概括它。**
  做法：不先定义风格 → 找参考 → 抽出该风格**最常用的元素** → 在自己的稿上做**细小的差异化**
- **借它的语言，不复制它的工艺限制。** 复古的四个特征（粗字重、手绘、几何分区、回形字/半调）
  来自当时的传播与成本限制——**今天没有那些限制**
- **参考与你要做的东西常常不是同一个风格。** 应该**比对它们的复杂度与手法**，
  然后**单独思考你的图需要什么**，而不是照搬

---

## 十一、材质族要够

按类别做法不同：**纸张类**（差异化材质）、**金属类**（斜面浮雕 + 双内阴影）、**塑料类**（高反射 + 主次反射）。

**材质族不足是会被看出来的**：参考里有皮革、透明垫、白纸、荧光胶带、金属订书钉、PVC 挂绳，
只交出纸与徽章两族，就是缺口——**写进缺口清单，不要当它不存在**。

---

## 禁止清单

- ❌ 把材质当成一份配方库，一种一种记下来抄
- ❌ 用渐变和不透明度做复杂度
- ❌ 用透明度做层次（分层是遮挡）
